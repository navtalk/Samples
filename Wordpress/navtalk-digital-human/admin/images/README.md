## How to Replace

1. Take screenshots in your WordPress + Elementor environment
2. Save them with the exact filenames listed above
3. Place them in this directory (`admin/images/`)
4. The admin settings page will automatically load them

## Notes

- Currently, the plugin uses CSS gradient placeholders
- Once you add actual PNG files here, they will replace the placeholders
- Make sure images are optimized for web (use JPEG/PNG compression)
- For best quality, use 2x resolution and scale down with CSS
