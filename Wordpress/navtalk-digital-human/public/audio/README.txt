NavTalk Audio Files
==================

This directory contains audio files for call start and end sounds.

Required files:
- call-start.mp3: Audio played when starting a call (recommended: 1-2 seconds)
- call-end.mp3: Audio played when ending a call (recommended: 1 second)

Audio specifications:
- Format: MP3
- Duration: 1-2 seconds
- File size: Recommended under 100KB
- Volume: Medium (will be played at 50% volume in the application)

You need to provide these MP3 files. Place them in this directory to enable call audio functionality.

If these files are missing, the plugin will still work normally but without audio feedback.
